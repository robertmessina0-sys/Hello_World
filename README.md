## Description

It demonstrates how **Python** and **SQL** can be applied alongside **Microsoft Excel** and **Power BI/Tableau** to automate financial data processing, structure relational databases, and generate operational insights.

## How to Run Program

1. **Database Queries (`.sql`):**
   - Import `business_analytics_queries.sql` into your database manager (e.g., PostgreSQL, SQLite, or MySQL Workbench).
   - Execute the relational queries against your target schema.

2. **Python Data Pipeline (`.py`):**
   - Ensure Python 3.x and required libraries are installed:
     ```bash
     pip install pandas numpy
     ```
   - Execute the script from your terminal:
     ```bash
     python financial_data_processing.py
     ```
